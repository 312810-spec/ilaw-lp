# ILAW rendering
The user requested Intentions, Learning Experiences, Assessing Learning, Ways Forward. These are implemented as configurable document sections. National mandate, exact wording, grade-level variations, period covered, and current requirements remain unverified. Never claim ILAW headings alone establish compliance.

Generated instructional decisions are pedagogical suggestions. Teachers review and adapt them. "Teacher-reviewed" is a teacher action, not DepEd approval. 1–5 sessions is an app limit, not a policy limit. Ways Forward thresholds are editable app defaults. No learner names, diagnoses, or personal information are requested.
