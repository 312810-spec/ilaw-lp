# Product specification
A navy/white teacher workbench with amber ILAW motif, readable type, generous controls and distinct I/L/A/W sections. Primary surface: recent plans and New lesson; no marketing landing page. Five progressive steps, explicit source state, optional learner/resources/preferences. Printable lesson document with plain headings and editable structured fields.

Acceptance journey: choose class → practice or custom/source competency → context/resources → guided or available real AI generation → understand rationale and checks → edit/reorder/targeted regeneration → autosave SQLite → review → reopen/duplicate/version restore → print/PDF via browser and DOCX. Search/filter history; mobile single-column; keyboard forms and live progress. No PII fields. Offline edit recovery does not replace server persistence.

Unresolved: authoritative current policy/dataset, independent market validation, real AI credential and production HTTPS/hosting. These are visible limitations rather than hidden placeholders.

Evidence log: anonymous category counts and notes per session, bounded by class size, with criterion/task snapshots and recording revision. Previous-session observations inform targeted session revision; unobserved learners remain unknown. Evidence categories are teacher judgments, not official grades. Editing a criterion/task flags recorded evidence for reinterpretation.
